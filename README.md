# 口袋文字冒險（pokemonwordRPG）

寶可夢文字版 RPG，純前端單頁，直接用瀏覽器開就能玩：

**https://owl1121.github.io/pokemonwordRPG/**

- 野外遇敵、捕捉、進化、超進化、異色
- 無盡塔、道館、傳說挑戰
- 性格、特性、攜帶道具、天氣、每日活動與節日活動
- 成就、稱號、簽到、任務、圖鑑
- 本傳招式、特性、太晶化／Z 招式／極巨化、寶可夢聯盟、對戰工廠
- 大量出現（連鎖提高異色率）、太晶／極巨團體戰、雙打對戰、對戰塔
- 交換所、野餐、圖鑑獎勵與護符
- 對戰卡片以每隻寶可夢的霧化底圖鋪底

存檔在瀏覽器的 localStorage，換手機或換瀏覽器請用選單裡的「備份／搬移存檔」。

程式結構見 [STRUCTURE.md](STRUCTURE.md)；自動測試：`cd tests && npm install && npm test`。
